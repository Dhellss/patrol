# patrol

Grab every file and reach the stairs. The cameras turn a quarter every time you move.

## Play

Open `index.html` in a browser. No build step, no dependencies.

## Rules

- Solid red is what the cameras see now. Faded red is where they sweep next.
- Step into either one and you are seen. Waiting counts as a move too.
- Every floor has a route. Three lives.

## Built with

Plain HTML, CSS and JavaScript.
